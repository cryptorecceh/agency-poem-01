A program that writes one short poem about agency — the power to choose and to act, and what passes between a person and an AI agent when one acts for the other. The poem holds a single image through three stanzas: a hand on an open door. The doing is handed over to the machine; the choosing stays, and the poem's turn is that the choosing was always the whole of it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the poem to `out/entry.txt` (or `/output/entry.txt` inside the grader's container). Node 22, standard library only, deterministic — the same poem every run.
